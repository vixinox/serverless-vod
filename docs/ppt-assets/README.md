# 答辩 PPT 素材目录

此目录用于答辩演示文稿 `docs/答辩演示.pptx` 的视觉素材管理。

## 目录约定

- `screenshots/`：系统界面截图（推荐 16:9，宽度 >= 1600px）
- 其它图像素材可按用途新增子目录

## 系统截图命名（与生成脚本绑定）

将以下文件放入 `docs/ppt-assets/screenshots/`，脚本会自动插入到“系统实现效果”页：

1. `home-search.png`：首页或搜索页
2. `watch-page.png`：视频播放页
3. `upload-pipeline.png`：上传与转码进度页
4. `studio-stat.png`：创作者工作室或统计页

若文件不存在，PPT 会显示“待替换截图”占位框，不会中断生成。

## 截图建议

- 建议使用本地运行环境采集：导航栏、关键内容区完整可见。
- 避免弹窗遮挡、调试边框、浏览器下载条等噪声。
- 保持同一缩放比例与同一主题，减少拼贴页视觉割裂。
