# 答辩学习手册总览

本目录是你的长期跟学材料。目标是两件事：

1. 让非技术评委也能秒懂你的项目。
2. 让你在追问时有问必答，不怕随机点名。

## 文件导航

- `01-daily-study-manual.md`：18天执行版学习计划（每天4小时）。
- `02-core-knowledge-explanations.md`：核心知识讲解（通俗版 + 技术版 + 追问点）。
- `03-aws-pipeline-deep-dive.md`：S3/Lambda/Step Functions/EventBridge/LocalStack 专题。
- `04-testing-defense-guide.md`：第6章测试答辩专项话术与边界说明。
- `05-high-frequency-qa-100-skeleton.md`：100题问答题库骨架（先填高频，再补长尾）。
- `06-agent-collab-playbook.md`：如何唤起 agent 协同学习（可复制口令）。
- `07-daily-checkin-template.md`：每日打卡模板。

## 使用方法（每天固定流程）

1. 打开 `01-daily-study-manual.md` 看今天任务。
2. 用 `02` 到 `04` 先补知识，再做口述训练。
3. 在 `05` 里完成当日新增问答卡。
4. 在 `07` 打卡复盘。
5. 遇到卡点，按 `06` 的口令请求 agent 协同。

## 每日4小时建议配比

- 80分钟：知识补漏（当天主题）。
- 60分钟：输出成果（PPT页、讲稿段、流程图、问答卡）。
- 40分钟：20道快问快答（计时）。
- 30分钟：8分钟陈述演练（录音复盘）。
- 30分钟：错题复训与二次背诵。

## 每日达成线

- 新增并掌握问答卡 >= 10条。
- 口述训练 >= 1次。
- 可展示成果 >= 1份。
- 错题回炉 >= 1轮。

## 跟学口令

你每天可以直接对我说：

`执行今天的答辩训练，按 docs/defense-study/01 的 Day X 带我走完整流程。`

如果当天只想做问答训练：

`基于 docs/defense-study/05，给我20题限时快问快答，答错就追问。`
