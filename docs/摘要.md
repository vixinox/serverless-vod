基于 AWS Serverless 架构的视频点播平台设计与实现
摘　要
随着在线视频业务的持续发展，传统视频平台在存储、转码与分发等环节面临扩展成本高、运维复杂和资源利用不均衡等问题。针对这些问题，本文设计并实现了一套基于 AWS Serverless 架构的视频点播平台。系统以前端应用、关系型数据库和云端媒体处理链路协同构成整体方案，采用 Next.js 16 与 React 19 构建前端，使用 PostgreSQL 与 Prisma 完成数据建模和持久化，并借助 Better Auth 实现用户认证与权限控制。在媒体处理方面，平台通过对象存储管理视频文件，利用 Step Functions 编排 Lambda 完成元数据提取、FFmpeg 转码、HLS 切片、封面抽取与状态回写，并结合 EventBridge 实现阶段反馈与状态同步。系统实现了视频上传、处理、发布、播放以及评论、收藏、播放列表和统计分析等功能。结果表明，该平台能够形成较完整的视频点播业务闭环，具有较好的模块化、扩展性和可维护性，也说明 AWS Serverless 架构在中小规模视频点播场景中具有较高的应用可行性。

关键词：AWS Serverless；视频点播平台；Next.js；Lambda；对象存储；工作流编排

Design and Implementation of a Video-on-Demand Platform Based on AWS Serverless Architecture

Abstract
With the continued growth of online video services, traditional video platforms face challenges such as high scaling costs, complex operations, and uneven resource utilization in storage, transcoding, and distribution. To address these issues, this paper designs and implements a video-on-demand platform based on an AWS serverless architecture. The system combines a frontend application, a relational database, and a cloud-based media-processing pipeline. Next.js 16 and React 19 are used to build the frontend, PostgreSQL and Prisma are adopted for data modeling and persistence, and Better Auth is used for authentication and access control. In the media-processing workflow, video files are managed through object storage, while Step Functions orchestrates Lambda functions for metadata extraction, FFmpeg transcoding, HLS packaging, thumbnail generation, and status updates. EventBridge is further introduced to provide stage feedback and state synchronization. The platform supports video upload, processing, publishing, playback, comment interaction, favorites, playlists, and analytics. The results show that the platform forms a relatively complete video-on-demand workflow with good modularity, scalability, and maintainability, demonstrating the practical feasibility of AWS serverless architecture for small and medium-sized video platforms.

Keywords: AWS Serverless; Video-on-Demand Platform; Next.js; Lambda; Object Storage; Workflow Orchestration
