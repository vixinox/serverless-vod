基于 AWS Serverless 架构的视频点播平台设计与实现
摘　要
随着在线视频业务的持续发展，传统视频平台在存储、转码与分发等环节面临扩展成本高、运维复杂、资源利用率不均衡等问题。针对上述问题，本文设计并实现了一套基于 AWS Serverless 架构的视频点播平台。系统采用 Next.js 16 与 React 19 构建前端应用，使用 PostgreSQL 和 Prisma 完成数据建模与持久化，并借助 Better Auth 实现用户认证与权限控制。在媒体处理流程中，平台以对象存储管理视频文件，通过 Step Functions 编排 Lambda 完成元数据提取、FFmpeg 转码、HLS 切片、封面抽取和状态回写，并结合 EventBridge 实现流水线阶段反馈与状态同步。系统已实现首页浏览、搜索、频道展示、视频播放、评论互动、收藏与播放列表、内容管理及统计分析等功能。实践结果表明，该平台能够完成视频上传、处理、发布与播放的完整业务闭环，具备较好的模块化、可扩展性和可维护性。研究结果表明，AWS Serverless 架构在视频点播场景中具有较高的应用可行性，可为中小规模视频平台的设计与实现提供参考。

关键词：AWS Serverless；视频点播平台；Next.js；Lambda；对象存储；工作流编排

Design and Implementation of a Video-on-Demand Platform Based on AWS Serverless Architecture

Abstract
With the continued growth of online video services, traditional video platforms face challenges such as high scaling costs, complex operation and maintenance, and uneven resource utilization in storage, transcoding, and distribution. To address these issues, this paper designs and implements a video-on-demand platform based on an AWS serverless architecture. The system uses Next.js 16 and React 19 to build the frontend application, PostgreSQL and Prisma for data modeling and persistence, and Better Auth for authentication and access control. In the media-processing workflow, video files are managed through object storage, while Step Functions orchestrates Lambda functions for metadata extraction, FFmpeg transcoding, HLS packaging, thumbnail generation, and status updates. EventBridge is further introduced to provide pipeline-stage feedback and state synchronization. The platform supports homepage browsing, search, channel display, video playback, comment interaction, favorites and playlists, content management, and analytics. Practical results show that the platform completes the full workflow of video upload, processing, publishing, and playback, with good modularity, scalability, and maintainability. The study indicates that the AWS serverless architecture is highly feasible for video-on-demand scenarios and can serve as a reference for the design and implementation of small and medium-sized video platforms.

Keywords: AWS Serverless; Video-on-Demand Platform; Next.js; Lambda; Object Storage; Workflow Orchestration
